# All City

Skate a copy of your own town and paint it before the other crews do. A
LinuxGroove game in Godot 4, built from OpenStreetMap by its own
Cartographer. The concept is idea 24 in
[game-ideas](https://github.com/LinuxGroove/game-ideas/blob/main/ideas/24-all-city.md).

Map data © OpenStreetMap contributors, under the Open Database License.
